# DocuScan Closed-Test Feedback Script

Required tester tasks:
1. Scan 5 pages and save.
2. Crop/filter/rotate at least one page.
3. Import images and create a PDF.
4. Open a PDF from device storage.
5. OCR search and open exact result page.
6. Create Study Mode subject and save into it.
7. Use at least two PDF tools.
8. Share one PDF.
9. Open Privacy & data.
10. Return on another day and reuse the app.

Questions:
- Any crash or freeze?
- Which screen was confusing?
- Was edge detection useful?
- Did saved PDF match edits?
- Did OCR find expected text?
- Was exact page correct?
- Was Study Mode understandable?
- Which PDF tool failed?
- Did privacy wording feel clear?
- What would make you uninstall?

Evidence:
- device model
- Android version
- app version
- reproduction steps
- sanitized screenshot/video if useful

Never use real private documents in bug reports.
